# CodeAlpha_Calculator

A sleek, modern, glassmorphic Web Calculator built using HTML, CSS, and vanilla JavaScript.

![Calculator Screenshot](favicon.png)

## 🌟 Features

- **Modern Glassmorphic Design**: Dark mode interface with dynamic lighting, smooth hover transitions, and responsive layout.
- **Full Expression Evaluation**: Allows entering and evaluating full math expressions (e.g., `89 * 6`, `100 + 50 * 2`, or `50%`).
- **Interactive Display**: Features a dual-line screen displaying current inputs and calculation history.
- **Complete Keyboard Shortcuts**:
  - Digits (`0-9`) and decimal point (`.`)
  - Basic Operators (`+`, `-`, `*`, `/`, `%`)
  - Calculate: `Enter` or `=`
  - Delete single character: `Backspace`
  - Clear all: `Escape`
- **Error Handling**: Graceful feedback for division by zero and invalid expressions.

## 📁 Project Structure

```
Calculator/
├── index.html       # Calculator UI layout
├── style.css        # Glassmorphic styles & design system
├── script.js        # Calculator expression engine & event handlers
├── package.json     # Node script configuration
└── README.md        # Documentation
```

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open terminal in the project directory.
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open your browser and navigate to `http://localhost:8080`.
